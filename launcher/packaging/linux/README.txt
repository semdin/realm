Thousand Realms for Linux

1. Extract this archive anywhere in your home folder.
2. Double-click ThousandRealms_Launcher. If your file manager only offers to
   open it as a file, double-click "Thousand Realms.desktop" and choose to
   trust it.
3. The launcher adds Thousand Realms to your application menu, downloads the
   game and keeps both up to date. No terminal is needed.

To remove it: delete this folder, then delete
~/.local/share/applications/thousand-realms.desktop and, for the game files,
~/.local/share/ThousandRealms.

Help: https://github.com/semdin/realm/issues


Thousand Realms - Linux kurulumu

1. Bu arşivi ev klasöründe istediğin yere çıkar.
2. ThousandRealms_Launcher dosyasına çift tıkla. Dosya yöneticin onu yalnızca
   dosya olarak açmayı öneriyorsa "Thousand Realms.desktop" dosyasına çift
   tıklayıp güvendiğini onayla.
3. Launcher, Thousand Realms'i uygulama menüne ekler, oyunu indirir ve ikisini
   de güncel tutar. Terminal gerekmez.

Kaldırmak için: bu klasörü sil, ardından
~/.local/share/applications/thousand-realms.desktop dosyasını ve oyun dosyaları
için ~/.local/share/ThousandRealms klasörünü sil.

Yardım: https://github.com/semdin/realm/issues
